# Architettura

QTTabBar upstream fornisce la shell extension caricata da Esplora file.

Il livello italiano aggiunge:
1. localizzazione XML;
2. installer/riparatore;
3. rilevamento versione;
4. controlli Windows 10 x64;
5. diagnostica;
6. rollback e disinstallazione.

La v0.3.0 non modifica i binari upstream.
