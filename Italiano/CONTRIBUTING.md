# Contributing

Branch consigliati:

- `main`: versione testata;
- `develop`: sviluppo;
- `feature/<nome>`: nuove funzioni;
- `fix/<nome>`: correzioni;
- `upgrade/<versione>`: aggiornamenti upstream.

Regole:
1. mantenere PowerShell 5.1 compatibile;
2. `.ps1` in UTF-8 con BOM;
3. `.ps1/.cmd/.bat` con CRLF;
4. aggiornare `CHANGELOG.md`;
5. non committare log, segreti o binari upstream;
6. testare installazione, lingua, diagnostica e disinstallazione.
