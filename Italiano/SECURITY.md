# Security Policy

QTTabBar è una shell extension caricata in `explorer.exe`.

Prima di pubblicare Issue o log:
- rimuovere nomi utente;
- rimuovere nomi computer;
- rimuovere percorsi personali;
- rimuovere email, token, API key e credenziali.

Non committare file `.reg`, log di installazione, backup o segreti.
